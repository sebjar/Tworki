# Archiwum skryptów

Jednorazowe skrypty z budowy bazy przepisów: poprawki danych (`patch_*`), audyty i diagnostyka,
stare wersje budowania i planu tygodnia (zastąpione aplikacją), testy pobierania zdjęć.
Potok (`build_v2.py` → `przelicz.py` → `app_eksport.py`) ich nie używa.

Importują moduły z `skrypty/` po nazwie, więc przed ponownym użyciem przenieś skrypt
z powrotem do `skrypty/`.
